# Dados brutos — Garantia-Safra

Folhas mensais de pagamento do Garantia-Safra baixadas manualmente do Portal da Transparência
(julho de 2022 a setembro de 2026), usadas pelo workflow "Pipeline com dados reais" do branch `main`.

Links para download das bases do projeto:

- Garantia-Safra (Portal da Transparência / CGU): https://portaldatransparencia.gov.br/download-de-dados/garantia-safra
  — um `.zip` por mês em `https://portaldatransparencia.gov.br/download-de-dados/garantia-safra/AAAAMM`
- Chuva diária (NASA POWER): https://power.larc.nasa.gov/data-access-viewer/
  — API: https://power.larc.nasa.gov/docs/services/api/temporal/daily/
- Municípios (códigos IBGE/SIAFI e coordenadas): https://raw.githubusercontent.com/kelvins/municipios-brasileiros/main/csv/municipios.csv
- Limites dos estados (mapa do relatório): https://raw.githubusercontent.com/codeforamerica/click_that_hood/master/public/data/brazil-states.geojson

Código, documentação e dashboard: https://github.com/rnn0/PROEX · https://proex-web.vercel.app
